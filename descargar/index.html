Descargar APK

  1. Toca Descargar APK y espera a que termine.
  2. Abre el archivo descargado (en la barra de avisos o en Descargas).
  3. Si Android lo pide, permite instalar apps de esta fuente y vuelve atrás.
  4. Toca Actualizar (o Instalar si es la primera vez).

Si ya tienes Domio, se instala encima: tus hogares, listas y tareas se quedan.
